# Invoice Processing System

An AI-powered invoice automation system that monitors incoming emails, intelligently identifies and extracts invoice data from PDF attachments, and automatically consolidates the results into structured Excel reports.

## Overview

The system is designed to automate invoice processing by combining email integration, AI-powered document analysis, and structured data extraction.

## Key Features

- Email monitoring and integration with Microsoft Outlook.
- Automatic detection of invoice PDF attachments.
- AI-powered invoice classification and data extraction.
- Structured invoice data validation.
- Automated Excel report generation.
- REST API built with FastAPI.

## Technology Stack

- **Language:** Python 3.13
- **Backend:** FastAPI
- **AI Integration:** OpenAI API
- **Email Integration:** Microsoft Graph API
- **Data Validation:** Pydantic
- **PDF Processing:** PyMuPDF
- **Excel Processing:** OpenPyXL
- **Testing:** Pytest
- **Code Quality:** Ruff
- **Version Control:** Git & GitHub
